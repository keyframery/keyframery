## What runs

- **One** `MutationObserver` that watches for shadcn parts appearing and changing state
- **Two** listeners in the capture phase, `pointerdown` and `keydown`, that remember the last press
- Animations of `transform`, `opacity` and `filter`, which the browser runs off the main thread where it can. A few parts also animate size so the content around them moves instead of jumping: `height` for collapsible content, for the tab panel area when two panels differ in height, and for LoadCut and StateCut when the new content is taller or shorter; `width` for ValueCut when a number gains or loses digits
- Ghosts, the copies of leaving elements, which are removed as soon as their animation ends or is cancelled

Nothing runs while nothing changes.

## Size

The CLI copies `cuts.tsx`, its stylesheet and the engine into your project, without adding an animation package dependency. Install only the helpers you use. Exact bundled size depends on your framework and bundler; measure the production build in your app rather than treating source-file size as the shipped cost.

## Lists

ListCut measures its items once per render, in a layout effect. Only items in or near the viewport animate, so a list of thousands stays fast. Key items by a stable id, and avoid re-rendering the whole list on every keystroke elsewhere on the page.

## Slow devices

Blur is the most expensive part of a rack focus. If you target low-end phones, turn it off:

```css
:root {
  --kf-blur: 0px;
}
```
