## What it fixes

A stock skeleton blinks on for a moment even when the data is fast, then snaps to content of a different height, and the page jumps. LoadCut fixes both:

- **Fast data:** it waits `--kf-hold` (300 ms) before showing the skeleton. During the wait, the skeleton's space is reserved but invisible, so nothing jumps. If the data arrives in time, you never see the skeleton.
- **Slow data:** once shown, the skeleton stays at least 400 ms, so it never flashes. Then it dissolves into the content over 240 ms while the height morphs from the skeleton's to the content's.

## Install

```bash
npx shadcn add @keyframery/load-cut
```

## Usage

```tsx
import { LoadCut } from "@/components/keyframery/load-cut"
import { Skeleton } from "@/components/ui/skeleton"

<LoadCut loading={isLoading} skeleton={<Skeleton className="h-32" />}>
  <RevenueChart data={data} />
</LoadCut>
```
