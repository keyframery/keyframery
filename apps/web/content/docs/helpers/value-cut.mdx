## What it fixes

When a stock number changes, it just changes, and nobody notices. ValueCut rolls only the digits that changed, in the direction of the change. Meanwhile the whole value punches in: it scales to 1.06 and back over 300 ms. Text values, like a status, crossfade with a 6px slide.

## Install

```bash
npx shadcn add @keyframery/value-cut
```

## Usage

```tsx
import { ValueCut } from "@/components/keyframery/value-cut"

<ValueCut value={visitors} format={{ notation: "compact" }} />
<ValueCut value={price} format={{ style: "currency", currency: "USD" }} locale="en-US" />
<ValueCut value={order.status} announce />
```
