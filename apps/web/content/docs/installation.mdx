You need a project with shadcn/ui set up, so `components.json` exists. Base UI and Radix both work.

<Steps>
<Step>

### Register Keyframery and install it

```bash
npx shadcn registry add "@keyframery=https://keyframery.com/r/{name}.json"
npx shadcn add @keyframery/cuts
```

The first command adds Keyframery's registry to `components.json`, once per project. The second copies `components/keyframery/cuts.tsx`, its stylesheet and a small engine in `lib/keyframery/` into your project. No npm packages are added.

**You should see** `"@keyframery"` under `registries` in `components.json`, and a new `components/keyframery/` folder.

</Step>
<Step>

### Render `<Cuts />` once, at the root

<Tabs items={["Next.js", "Vite", "React Router"]}>
<Tab value="Next.js">

```tsx title="app/layout.tsx"
import { Cuts } from "@/components/keyframery/cuts"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        {children}
        <Cuts />
      </body>
    </html>
  )
}
```

</Tab>
<Tab value="Vite">

```tsx title="src/main.tsx"
import { StrictMode } from "react"
import { createRoot } from "react-dom/client"

import { Cuts } from "@/components/keyframery/cuts"

import App from "./App"
import "./index.css"

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <App />
    <Cuts />
  </StrictMode>,
)
```

</Tab>
<Tab value="React Router">

```tsx title="app/root.tsx"
import { Outlet } from "react-router"

import { Cuts } from "@/components/keyframery/cuts"

export default function App() {
  return (
    <>
      <Outlet />
      <Cuts />
    </>
  )
}
```

</Tab>
</Tabs>

**You should see** a `data-kf` attribute on the `<html>` element in your browser's dev tools. `<Cuts />` sets it while it runs.

</Step>
<Step>

### Open a dialog

Open any dialog in your app.

**You should see** it grow out of the button you pressed, and close back into it. Tabs now slide, sheets push the page back, and toasts fly from the button that made them.

</Step>
</Steps>

## If the dialog still pops into the middle

- Make sure `<Cuts />` is rendered once, in the root layout or entry file.
- Check that your dialog's content element has `data-slot="dialog-content"`. Components added by shadcn CLI 3 and later have it; older copies don't. Run `npx shadcn add dialog` again to update yours.
- If the CLI answered `Unknown registry "@keyframery"`, run the first command of step 1 again, or add the registry to `components.json` by hand:

```json title="components.json"
{
  "registries": {
    "@keyframery": "https://keyframery.com/r/{name}.json"
  }
}
```

## Next

- See [what's automatic](/docs/automatic) now that `<Cuts />` is running.
- Choose a complete [motion theme](/docs/motion-themes) in the [builder](/theme), then copy its configured `<Cuts />` and CSS.
- Animate [lists](/docs/helpers/list-cut), [numbers and statuses](/docs/helpers/value-cut), [skeleton loading](/docs/helpers/load-cut), [whole-content states](/docs/helpers/state-cut) and [cards that open into a page](/docs/helpers/match-cut). Each installs by name, for example `npx shadcn add @keyframery/state-cut`, and uses the same root `<Cuts />`.
- To try the layer without registering first, `npx shadcn add https://keyframery.com/r/cuts.json` installs it by URL. That works for `cuts` only, because the other components depend on it.
