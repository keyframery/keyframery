## What moves

| When | What you see | Timing | How |
|---|---|---|---|
| It turns invalid after a submit or blur | One short shake | 240 ms | Automatic |

## Install

Input is shadcn's own component. With `<Cuts />` in your root layout ([Quick start](/docs/installation)), there's nothing else to add:

```bash
npx shadcn add input
```

## Turn it off

Put `data-cut="none"` on a input (or anything around it) to keep shadcn's own motion there. `<Cuts responses="none" />` turns off every response across the app and keeps the cuts. With reduced motion, movement becomes a short fade or nothing.
