## Which cut it uses

The command menu is a dialog, so it uses the **Rack focus** cut too. A cut is how something arrives on the screen and how it leaves. It grows out of the button you pressed, or from the middle when you open it with a keyboard shortcut. There are 3 to pick from, and each one is a single prop:

<CutCards menu="dialog">

| Cut | What you see | Code |
|---|---|---|
| Rack focus (default) | Grows out of the button you pressed, a little soft, then sharpens. Closing goes back into the button. | `<Cuts dialog="rack-focus" />` |
| Punch in | Pops up in the middle with a tiny bounce. Closing shrinks it away. | `<Cuts dialog="punch-in" />` |
| Fade | Fades in where it stands. Nothing moves. | `<Cuts dialog="fade" />` |

</CutCards>

The command menu follows the `dialog` prop, the same one that changes every dialog and alert dialog.

## What it fixes

`CommandDialog` is a dialog, so it gets the same rack focus: it grows out of the button you pressed, or from the centre when you open it with a shortcut. The search on this site runs on it. Press ⌘K to try it.

## Install

```npm
npx shadcn add command
```

## Change it

Every change is one prop. The controls at the top of the page try them live.


### Make it faster or slower

`pace` multiplies every duration: `1.6` is slower, `0.6` is faster.

```tsx
// In your root layout: every motion in your app
<Cuts pace={1.6} />
```

A keyboard shortcut counts as a press only when a focused element receives it. A global ⌘K listener has no opener, so the menu opens from the middle.

### Turn it off

```tsx
// In your root layout: no motion on any dialog or command menu
<Cuts dialog="none" />
```

With reduced motion turned on in the system settings, movement becomes a short fade or nothing.

## Props

**On `<Cuts />`**, in your root layout:

| Prop | Values | Default | What it does |
|---|---|---|---|
| `dialog` | `"rack-focus" \| "punch-in" \| "fade" \| "none"` | `"rack-focus"` | The cut for dialogs, alert dialogs and the command menu. |
| `pace` | `number` | `1` | Multiplies every duration in your app. |

**In your global CSS:**

| Prop | Values | Default | What it does |
|---|---|---|---|
| `--kf-ease` | `string` | `cubic-bezier(0.22, 1, 0.36, 1)` | The curve things arrive on. Or pick a theme at [/theme](/theme). |
| `--kf-ease-exit` | `string` | `cubic-bezier(0.5, 0, 0.75, 0)` | The curve things leave on. |
