## Which cut it uses

Message moves with **ListCut**: a small Keyframery component you wrap around the part that changes.

## What moves

| When | What you see | Timing | How |
|---|---|---|---|
| A message arrives | Flies from the composer, or slides in | 260–380 ms | [ListCut](/docs/helpers/list-cut) |

## Install

Install [ListCut](/docs/helpers/list-cut) and wrap the part that changes:

```npm
npx shadcn add @keyframery/list-cut
```

## Change it

Every change is one prop. The controls at the top of the page try them live.

### Make it faster or slower

`pace` multiplies every duration: `1.6` is slower, `0.6` is faster.

```tsx
<ListCut pace={1.6}>…</ListCut>
```

### Turn it off

```tsx
<ListCut cut="none">…</ListCut>
```

With reduced motion turned on in the system settings, movement becomes a short fade or nothing.

## Props

**On `<ListCut>`:**

| Prop | Values | Default | What it does |
|---|---|---|---|
| `pace` | `number` | `1` | Multiplies every duration of this one. |
| `cut` | `"none"` | – | "none" swaps it instantly. |

**In your global CSS:**

| Prop | Values | Default | What it does |
|---|---|---|---|
| `--kf-ease` | `string` | `cubic-bezier(0.22, 1, 0.36, 1)` | The curve things arrive on. Or pick a theme at [/theme](/theme). |
| `--kf-ease-exit` | `string` | `cubic-bezier(0.5, 0, 0.75, 0)` | The curve things leave on. |
