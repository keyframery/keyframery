## What it fixes

Drawers already have good motion: they follow your finger. What they're missing is depth. With `slide-sink`, the page behind steps back as the drawer rises, the way iOS sheets do. The drawer's own swipe and spring are never touched.

It works with both drawers: Base UI's and the Radix base's Vaul drawer.

## Install

```bash
npx shadcn add drawer
```
