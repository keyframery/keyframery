To add shadcn/ui animations with a coding agent, connect it to `https://keyframery.com/mcp`. The read-only server supplies documentation, helper APIs, installation snippets and motion themes. Claude Code can also install a plugin that explains when to use each cut. Assistants without MCP can read the same docs as Markdown.

You need an existing React project with shadcn/ui configured to install the components. Base UI and Radix are both supported; see [installation prerequisites](/docs/installation) and [tested versions](/docs/compatibility#tested-versions).

## Claude Code plugin

The plugin teaches Claude when to use each cut and connects it to the Keyframery MCP server. In Claude Code, run:

```bash
/plugin marketplace add keyframery/keyframery
/plugin install keyframery@keyframery
```

Then ask for what you want, for example "add Keyframery to this app" or "animate the inbox list".

## MCP server

The server is at `https://keyframery.com/mcp`. It needs no Keyframery account and exposes four read-only tools. It receives the arguments your client sends; it cannot inspect your local files or make project edits. Your coding agent performs the installation and edits in your workspace.

| Tool | What it does |
|---|---|
| `list_kinds` | The seven kinds of change, with the cut, install command and snippet for each |
| `search_docs` | Searches the docs and returns matching pages |
| `get_doc` | Returns one docs page as Markdown, such as `helpers/list-cut` |
| `make_theme` | Starts from Quiet, Crisp or Expressive plus overrides, and returns `<Cuts />`, CSS and installation handoff |

Choose a profile in the [theme builder](/theme) and copy its agent prompt to carry the exact theme into your project. An agent can also call `make_theme` with `profile: "crisp"` and individual settings such as `tabs: "fade"`. The tool generates instructions; it does not edit your project.

## Try one concrete agent task

After connecting your client below, open your app repository and ask:

```text
Add Keyframery to this existing shadcn/ui app. First call list_kinds,
then read installation, components/dialog and helpers/list-cut with get_doc.
Check whether this project uses Base UI or Radix before composing triggers.
Keep one root <Cuts /> and preserve the current dialog's accessible title,
description and focus behavior. Animate the release checklist with ListCut:
keep stable item ids and support add, remove and reorder.
Use the installed component APIs, keep reduced-motion support, and run the
project's existing checks. Report the files changed and how to try the result.
```

For a smaller change, ask for just the [dialog opening from its trigger](/docs/components/dialog#working-example-review-a-release) or the [add/remove/reorder checklist](/docs/helpers/list-cut#working-example-a-release-checklist). The server provides reference material; the agent still needs to inspect your app and verify its changes.

## Connect your client

### Claude Code

Without the plugin:

```bash
claude mcp add --transport http keyframery https://keyframery.com/mcp
```

### Claude

On the web or desktop: open Settings, then Connectors, add a custom connector, and paste `https://keyframery.com/mcp`.

### Codex

The Codex CLI and the IDE extension share one setting:

```bash
codex mcp add keyframery --url https://keyframery.com/mcp
```

Or add it to the config file yourself:

```toml title="~/.codex/config.toml"
[mcp_servers.keyframery]
url = "https://keyframery.com/mcp"
```

### Cursor

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "keyframery": { "url": "https://keyframery.com/mcp" }
  }
}
```

### VS Code (GitHub Copilot)

```json title=".vscode/mcp.json"
{
  "servers": {
    "keyframery": { "type": "http", "url": "https://keyframery.com/mcp" }
  }
}
```

### Gemini CLI

```bash
gemini mcp add --scope user --transport http keyframery https://keyframery.com/mcp
```

### Any other MCP client

Add a streamable HTTP server with the address `https://keyframery.com/mcp`. A client that only runs local servers can reach it through `npx -y mcp-remote https://keyframery.com/mcp`.

## Verify the connection

Restart or reload the client if it does not discover the new server. Ask it to call `list_kinds`, then `get_doc` with `path: "components/dialog"`. You should get the seven change kinds followed by the dialog's installation and usage documentation. Listing a server in a config file alone does not establish that it is connected.

If a tool call fails, check the client's MCP connection status and logs. Use the HTTPS endpoint above with Streamable HTTP, and check whether your organization permits custom MCP servers. If CLI installation later reports an unknown `@keyframery` registry, use the [registry fallback](/docs/installation#if-the-dialog-still-pops-into-the-middle).

The client configuration formats are documented by [Claude Code](https://code.claude.com/docs/en/mcp), [Cursor](https://cursor.com/docs/context/mcp), [VS Code](https://code.visualstudio.com/docs/agent-customization/mcp-servers) and [Gemini CLI](https://geminicli.com/docs/tools/mcp-server/). Client interfaces can change; use their documentation if your installed version differs.

## llms.txt

The docs are also published as plain text:

| URL | What it has |
|---|---|
| [`/llms.txt`](/llms.txt) | an index of every page, with one line each |
| [`/llms-full.txt`](/llms-full.txt) | every page in full, in one file |
| any docs page + `.mdx` | that page as Markdown, for example [`/docs/helpers/list-cut.mdx`](/docs/helpers/list-cut.mdx) |

Paste `https://keyframery.com/llms-full.txt` into a chat, or add a line to your project rules. Codex and most other agents read `AGENTS.md`; Claude Code reads `CLAUDE.md`.

```md title="AGENTS.md"
This project uses Keyframery for motion (https://keyframery.com/llms-full.txt).
Use ListCut for lists that change, ValueCut for numbers and statuses that change,
LoadCut for skeletons, StateCut for whole-content state switches,
and MatchCut for a card that opens into a detail view. Keep one root <Cuts />.
Use the chosen motion theme's Cuts props and CSS variables.
Avoid duplicating animations on supported parts already handled by Keyframery.
```
