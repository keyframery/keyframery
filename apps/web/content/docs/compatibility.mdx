Every shadcn component works with `<Cuts />` mounted: no errors, and focus and accessibility intact. Components where the screen changes get a **cut**. Controls you press, tick or drag get a **response** on the control itself. Parts that never change (labels, separators, keyboard shortcuts) stay still on purpose.
