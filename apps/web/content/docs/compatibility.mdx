Every shadcn component works with `<Cuts />` mounted: no errors, and focus and accessibility intact. Components where the screen changes get a **cut**. Controls you press, tick or drag get a **response** on the control itself. Parts that never change (labels, separators, keyboard shortcuts) stay still on purpose.

## Tested versions

The test suite installs Keyframery with this shadcn CLI into two Next.js apps that hold every shadcn component, one on Base UI and one on Radix, and runs each cut in all three browsers. Before each release, a drift check compares those components with what shadcn's registry serves that day.
