## Use Keyframery Create

<Steps>
<Step>

### Build your preset

Open [Keyframery Create](/create) and pick your colours, corners, font and motion. Copy the command under the preview.

</Step>
<Step>

### Create the project

```npm
npx shadcn@latest init -t react-router
```

</Step>
<Step>

### Add the preset

Run the command you copied from the project's folder:

```npm
npx shadcn@latest add @keyframery/preset-<code>
```

It writes the colours, corners and motion into `app/app.css`. A preset with a font installs it from Fontsource and imports it there too.

</Step>
<Step>

### Add components

```npm
npx shadcn@latest add @keyframery/tabs
```

Then [use it in a route](#use-it).

</Step>
</Steps>

## Use the CLI

<Steps>
<Step>

### Create the project

```npm
npx shadcn@latest init -t react-router
```

For a project inside a monorepo, add `--monorepo`.

</Step>
<Step>

### Add components

```npm
npx shadcn@latest add @keyframery/tabs
```

The files land in `app/components/keyframery/`, and the motion tokens go into `app/app.css`.

</Step>
<Step>

### Use it

```tsx title="app/routes/home.tsx"
import { Tabs, TabsList, TabsPanel, TabsPanels, TabsTab } from "~/components/keyframery/tabs"

export default function Home() {
  return (
    <Tabs defaultValue="account">
      <TabsList aria-label="Settings">
        <TabsTab value="account">Account</TabsTab>
        <TabsTab value="password">Password</TabsTab>
      </TabsList>
      <TabsPanels>
        <TabsPanel value="account">Account settings</TabsPanel>
        <TabsPanel value="password">Password settings</TabsPanel>
      </TabsPanels>
    </Tabs>
  )
}
```

</Step>
</Steps>

## Existing Project

<Steps>
<Step>

### Check the setup

You need React 19, Tailwind CSS v4 and the `~/*` alias pointing at `app/`. Apps made with `create-react-router` have both. Then set up the CLI:

```npm
npx shadcn@latest init
```

</Step>
<Step>

### Add components

```npm
npx shadcn@latest add @keyframery/tabs
```

</Step>
</Steps>

## Notes for React Router

- **Imports.** Keyframery's files are written with `@/`. The CLI rewrites them to `~/` as it installs, so `react-router typegen && tsc` passes without edits.
- **Server rendering.** The components render on the server and start animating once the page hydrates.
- **Motion style.** Put `data-motion="calm"` on `<html>` in `app/root.tsx`, or wrap the `<Outlet />` in `<KeyframeryProvider motion="calm">`.
