## Use Keyframery Create

Build your preset at [Keyframery Create](/create): base and theme colours, corners, font, motion style, speed and bounce. Copy the command it gives you and run it in your project:

```npm
npx shadcn@latest add @keyframery/preset-<code>
```

Every framework guide below starts with this path.

## Use the CLI

Scaffold a new project with shadcn's template for your framework, then add components:

```npm
npx shadcn@latest init -t [framework]
```

```npm
npx shadcn@latest add @keyframery/tabs
```

Templates: `next`, `vite`, `start`, `react-router` and `astro`. For Laravel, create the app first with `laravel new` and the React starter kit.

## Existing Project

You need React 19, Tailwind CSS v4 and a project set up for the shadcn CLI, so `components.json` exists. If it doesn't, run `npx shadcn@latest init` first, or follow your framework's guide below.

Already using shadcn/ui components? They keep working next to Keyframery. We ran both libraries in one project, and the two state classes that need a new name are in [UI SDK with shadcn/ui](/blog/ui-sdk-with-shadcn).

Prefer to let your coding agent do it? <a href="/docs/ai-tools">Use the skill or the prompt</a>.

<Steps>
<Step>

### Add a component

```npm
npx shadcn@latest add @keyframery/tabs
```

This copies two files into your project's components folder and adds the motion tokens to your global CSS:

```text
components/keyframery/tabs.tsx
components/keyframery/primitives/tabs.tsx
```

The folder follows your project's `components` alias, so it is `app/components/keyframery/` in React Router and `resources/js/components/keyframery/` in Laravel. UI SDK (`@ui-sdk/react` and `@ui-sdk/core`) is installed for you, pinned to the version the components are tested with. Keyframery is in shadcn's registry index, so the CLI finds `@keyframery` with nothing to set up first.

**You should see** a new `components/keyframery/` folder.

</Step>
<Step>

### Use it

```tsx title="app/settings/page.tsx"
import { Tabs, TabsList, TabsPanel, TabsPanels, TabsTab } from "@/components/keyframery/tabs"

export default function Settings() {
  return (
    <Tabs defaultValue="general">
      <TabsList>
        <TabsTab value="general">General</TabsTab>
        <TabsTab value="billing">Billing</TabsTab>
      </TabsList>
      <TabsPanels>
        <TabsPanel value="general">…</TabsPanel>
        <TabsPanel value="billing">…</TabsPanel>
      </TabsPanels>
    </Tabs>
  )
}
```

**You should see** the key stretch across to the tab you click, and the panel slide in from that side.

</Step>
<Step>

### Pick how it moves

Subtle is the default: quick fades and slides, no bounce. To give every component more motion at once, set a motion style on `<html>`:

```html
<html data-motion="springy">
```

The values are `subtle`, `calm`, `springy`, `snappy` and `playful`. More in [Motion styles](/docs/motion-styles).

</Step>
</Steps>

### Install everything

```npm
npx shadcn@latest add @keyframery/all
```

Every component, in one command. Your bundler only ships the ones you import.

## What the CLI adds to your CSS

The first component you install adds a small block of motion tokens to your global stylesheet: one speed setting, a flourish setting, three easings, and the five motion styles. Every component reads them.

```css
:root {
  --kf-speed: 0.7; /* Subtle: quick */
  --kf-flourish: 0; /* Subtle: no stretches, pops or entrances */
  --ease-house: cubic-bezier(0.22, 1, 0.36, 1);
  --ease-spring: cubic-bezier(0.22, 1, 0.36, 1); /* the styles set springs here */
  --ease-pop: cubic-bezier(0.22, 1, 0.36, 1);
}
[data-motion="springy"] {
  --kf-speed: 1;
  --kf-flourish: 1;
  --ease-spring: linear(/* a spring, written as a CSS easing */);
  --ease-pop: linear(/* a livelier spring for small payoffs */);
}
/* …and calm, snappy and playful */
```

Installing by hand? The [manual guide](/docs/installation/manual#add-the-motion-tokens) has the whole block to paste.
