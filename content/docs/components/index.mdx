These are animated versions of the components in [Vercel's UI SDK](https://ui-sdk.dev/docs/react/components) (`@ui-sdk/react`). Each one renders UI SDK's own component underneath, so keyboard, focus and screen-reader behaviour stay exactly as UI SDK ships them, and adds the motion in plain CSS. Four of them (Badge, Card, Kbd and Skeleton) have no UI SDK counterpart and are built from plain elements with the same motion. New to UI SDK? Start with [what it is and how to animate it](/blog/what-is-vercel-ui-sdk).

Install any of them by name, or all at once:

```npm
npx shadcn@latest add @keyframery/all
```
