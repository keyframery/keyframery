You need React 19, Tailwind CSS v4 and a project set up for the shadcn CLI, so `components.json` exists. If it doesn't, run `npx shadcn@latest init` first.

Prefer to let your coding agent do it? <a href="/docs/ai-tools">Use the skill or the prompt</a>.

<Note title="Recommended for new projects:">
Use [Keyframery Create](/create) to pick your colours, corners, font and motion visually, then install them as a [preset](/docs/presets) with one command.
</Note>

## Install one component

<Steps>
<Step>

### Add a component

```npm
npx shadcn@latest add @keyframery/tabs
```

This copies two files into your project and adds the motion tokens to your global CSS:

```text
components/keyframery/tabs.tsx
components/keyframery/primitives/tabs.tsx
```

UI SDK (`@ui-sdk/react` and `@ui-sdk/core`) is installed for you, pinned to the version the components are tested with. Keyframery is in shadcn's registry index, so the CLI finds `@keyframery` with nothing to set up first.

**You should see** a new `components/keyframery/` folder.

</Step>
<Step>

### Use it

```tsx title="app/settings/page.tsx"
import { Tabs, TabsList, TabsPanel, TabsPanels, TabsTab } from "@/components/keyframery/tabs"

export default function Settings() {
  return (
    <Tabs defaultValue="general">
      <TabsList>
        <TabsTab value="general">General</TabsTab>
        <TabsTab value="billing">Billing</TabsTab>
      </TabsList>
      <TabsPanels>
        <TabsPanel value="general">…</TabsPanel>
        <TabsPanel value="billing">…</TabsPanel>
      </TabsPanels>
    </Tabs>
  )
}
```

**You should see** the key stretch across to the tab you click, and the panel slide in from that side.

</Step>
<Step>

### Pick how it moves

Springy is the default. To change the feel of every component at once, set a motion style on `<html>`:

```html
<html data-motion="calm">
```

The values are `calm`, `springy`, `snappy` and `playful`. More in [Motion styles](/docs/motion-styles).

</Step>
</Steps>

## Install everything

```npm
npx shadcn@latest add @keyframery/all
```

Every component, in one command. Your bundler only ships the ones you import.

## What the CLI adds to your CSS

The first component you install adds a small block of motion tokens to your global stylesheet: one speed setting, three easings, and the four motion styles. Every component reads them.

```css
:root {
  --kf-speed: 1;
  --ease-house: cubic-bezier(0.22, 1, 0.36, 1);
  --ease-spring: linear(/* a spring, written as a CSS easing */);
  --ease-pop: linear(/* a livelier spring for small payoffs */);
}
```
